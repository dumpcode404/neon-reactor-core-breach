NEON REACTOR: CORE BREACH — an original arena action-roguelite. Hold the reactor core through 10 escalating waves, chain kills for combo multipliers, draft 1-of-3 upgrades between waves, and destroy the MOTHERSHIP to win. Pure Canvas + WebAudio, zero network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD move, mouse aim, click / Space fire and dash, 1/2/3 draft upgrades, P pause, M mute, R restart. Touch supported.
